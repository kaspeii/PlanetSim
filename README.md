# 🌍 PlanetSim

**PlanetSim** — процедурный 3D-симулятор формирования планет земного типа на Rust и игровом движке Bevy. Проект моделирует связанную физическую цепочку: от движения литосферных плит и вулканизма до глобальной циркуляции атмосферы, океанических течений, почвообразования, речной сети и распределения биомов.

---

## ✨ Ключевые возможности

### 1. Геология, тектоника и литология (`domains/tectonics`)
* **Сферическая геодезическая сетка:** Мир строится на дуальной икосферической сетке (гексагоны и 12 пентагонов), обеспечивающей равномерную площадь ячеек без полярных искажений.
* **Тектоника плит:** Генерация океанических и континентальных плит Вороного с нелинейным 3D-искажением границ (Domain Warping) и расчетом движения через полюса вращения Эйлера.
* **Орогенез и вулканизм:** Моделирование конвергентных, дивергентных и трансформных границ (горные цепи, глубоководные желоба, срединно-океанические хребты, рифты), а также вулканических цепей над мантийными плюмами (горячими точками).
* **Коренные породы (Литология):** Формирование 10 типов пород (`RockType`: океанический базальт, пелагические осадки, гранит, гнейс/сланец, андезит, трапповый базальт, песчаник, глинистый сланец, известняк, аллювий) с индивидуальными физическими свойствами (эродируемость, минеральный состав).

### 2. Климат, атмосфера и океан (`domains/climate`)
* **Континентальность в радианах:** Расчет удаленности от океанов и крупных массивов суши через Flood Fill и двойной поиск в ширину (BFS) в угловых радианах, что делает физику инвариантной к разрешению сетки.
* **Термодинамика и сезонный цикл:** Параллельный расчет 3 сезонов (Весна/Осень, Лето, Зима) с учетом наклона оси вращения планеты, широтной инсоляции, высотного градиента температуры (Lapse Rate) и нелинейной обратной связи ледяного альбедо.
* **Атмосферная циркуляция и течения:** Формирование 7 широтных барических поясов (ячейки Хэдли, Феррела, полярные) и термических аномалий давления над материками. Расчет 3D-ветров с учетом отклонения силой Кориолиса и барьерного торможения о горы, а также ветровых поверхностных океанических течений.
* **Влага и осадки:** Итеративный перенос водяного пара ветрами, орографический сброс осадков на наветренных склонах (эффект дождевой тени), конвективные ливни в зонах низкого давления и рециклинг влаги растительностью и почвой.

### 3. Почвы, гидрология и биомы (`domains/hydrology`)
* **Почвообразование (модель CLORPT):** Вычисление текстуры почвы по треугольнику USDA ($\text{песок} + \text{ил} + \text{глина} = 1.0$), глубины профиля, влагоемкости корнеобитаемого слоя и водопроницаемости на основе коренной породы, климата и уклона рельефа. Классификация на 10 почвенных групп (`SoilType`: подзолы, черноземы, латериты, андисоли, гелисоли и др.).
* **Гидрология и 3D-реки:** Трассировка поверхностного и грунтового стока с заполнением бессточных впадин и озер. Процедурная генерация 3D-меша речной сети со сглаживанием русел кривыми Безье, узлами слияния притоков, шириной, зависящей от полноводности и твердости породы, а также водопадами на уступах рельефа.
* **Экология и обратная связь:** Классификация 19 морских, наземных и интразональных биомов (`Biome`: от ледниковых щитов и тундры до саванн, дождевых лесов, болот и пойменных оазисов). Поддержка двухпроходной обратной связи (`coupled_climate_feedback`), при которой альбедо и влажность сформированных биомов влияют на климат.

### 4. Производительность, рендер и сохранения
* **Фоновая многопоточная генерация:** Все тяжелые расчеты выполняются асинхронно в `AsyncComputeTaskPool` и распараллеливаются через `rayon`, не блокируя интерфейс и вращение камеры. Экран загрузки отображает живой лог этапов с таймингами в миллисекундах.
* **Быстрое обновление 3D-глобуса:** Разделение полной пересборки топологии меша (`rebuild_mesh`), быстрого изменения высот воды (`reposition_mesh`) и мгновенной перекраски вершин (`recolor_mesh`) с отложенным на 1 кадр освобождением старых GPU-буферов.
* **Система сохранений:** Сохранение и загрузка планет целиком в компактном бинарном формате (`saves/planets/*.planet`) с автоматической догенерацией недостающих стадий, а также экспорт легковесных пресетов настроек в JSON (`saves/configs/*.json`).

## 🚀 Быстрый старт и сборка

В проекте используется командный раннер [`just`](https://github.com/casey/just) (современная кроссплатформенная альтернатива `make`), автоматизирующий установку системных зависимостей, сборку и тестирование. Также настроен файл `rust-toolchain.toml` (автоматически подтягивающий компоненты `rustfmt`, `clippy` и `llvm-tools-preview`) и быстрая линковка через `lld` в `.cargo/config.toml`.

### 1. Предварительные требования
1. **Rust (`stable`):** Установите через [rustup.rs](https://rustup.rs/):
   ```bash
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```
2. **Раннер `just` (рекомендуется):**
   ```bash
   cargo install just
   ```
   *(Либо через пакетный менеджер вашей ОС: `sudo apt install just`, `brew install just`, `winget install Casey.Just`).*

### 2. Первичная настройка окружения
```bash
# Установка системных библиотек для Bevy, линкера lld (на Linux) и компонентов Rust
just setup

# Опционально: установка вспомогательных cargo-утилит (cargo-watch, cargo-audit, flamegraph)
just setup-tools
```

> **Примечание для Linux (Ubuntu/Debian):** Если вы не используете `just setup`, установите системные пакеты для Bevy и быстрой линковки вручную:
> ```bash
> sudo apt-get update && sudo apt-get install -y g++ clang lld pkg-config libx11-dev libasound2-dev libudev-dev libwayland-dev libxkbcommon-dev
> ```

### 3. Запуск проекта
```bash
# Быстрый запуск для разработки (с динамической линковкой Bevy)
just dev
# (эквивалентно: cargo run --features bevy/dynamic_linking)

# Стандартный запуск отладочной сборки
just run

# Сборка оптимизированной релизной версии
just release
```

> **Примечание при первой сборке (Out of Memory):** Первая «холодная» компиляция движка Bevy во все потоки процессора параллельно с работающей IDE (`rust-analyzer`) может потребовать до 12–16 ГБ свободной памяти. На системах с ограниченным объемом ОЗУ или отключенным файлом подкачки используйте щадящий режим для первой сборки: `just dev-low-mem` (или флаг `-j 4`).

## 🎮 Управление и горячие клавиши

### Камера (3D-глобус)
| Действие | Управление |
| :--- | :--- |
| **Вращение планеты** | Зажать `ЛКМ` и перемещать мышь (с поддержкой инерции) |
| **Приближение / Отдаление** | Колесо мыши, скролл трекпада или жест щипка (Pinch на macOS) |
| **Приближение с клавиатуры** | `Shift` + `=` или `Numpad +` |
| **Отдаление с клавиатуры** | `-` или `Numpad -` |
| **Сброс зума к стандартному** | Клавиша `=` (без Shift) или `СКМ` (средняя кнопка мыши) |

### Глобальные горячие клавиши
* **`R`** — Полный асинхронный пересчет планеты с нуля (начиная со стадии тектоники).
* **`Tab`** — Циклическое переключение 14 тематических слоев карты:
  $$\text{SpaceView} \rightarrow \text{Elevation} \rightarrow \text{TectonicPlates} \rightarrow \text{Lithology} \rightarrow \text{Temperature} \rightarrow \text{Humidity} \rightarrow \text{Precipitation} \rightarrow \text{Albedo} \rightarrow \text{Continentality} \rightarrow \text{Pressure} \rightarrow \text{Winds} \rightarrow \text{Soils} \rightarrow \text{SoilMoisture} \rightarrow \text{Biomes}$$

## 🏗 Архитектура проекта

Код организован по принципу изолированных вертикальных срезов (Vertical Slices) с однонаправленным потоком данных:

$$\text{Tectonics (Рельеф и Породы)} \longrightarrow \text{Climate (Тепло, Ветер, Осадки)} \longrightarrow \text{Hydrology (Почвы, Реки, Биомы)}$$

```text
src/
├── main.rs                          # Точка входа, инициализация окна и плагинов Bevy
├── world/                           # Ядро мира и глобальные состояния
│   ├── mod.rs                       # WorldPlugin, WorldConfig (радиус, детализация сетки)
│   ├── topology.rs                  # Построение сферической сетки (клетки, соседи, углы)
│   ├── pipeline.rs                  # PipelineSet, PipelineStage и флаги обновления меша
│   └── states.rs                    # Состояния приложения (MainMenu, InGame)
│
├── viewport/                        # 3D-сцена, камера и генерация геометрии
│   ├── mod.rs                       # ViewportPlugin, MapOverlay, ViewportViewConfig, гизмо оси/экватора
│   ├── mesh_globe.rs                # Генерация 3D-меша глобуса, отвесных стен гексов и лент рек
│   ├── camera_3d.rs                 # Инерционное вращение глобуса и управление зумом
│   └── hotkeys.rs                   # Обработка горячих клавиш (R, Tab)
│
├── ui/                              # Оболочка пользовательского интерфейса (bevy_egui)
│   └── mod.rs                       # Топ-бар сохранений, левая панель слоев, нижний таскбар, лог загрузки
│
└── domains/                         # Физические домены симуляции
    ├── mod.rs                       # DomainsPlugin, регистрация фонового генератора
    ├── generator.rs                 # Оркестратор асинхронной генерации и GenerationLogger
    ├── save.rs                      # Сериализация планет (.planet) и пресетов настроек (.json)
    │
    ├── tectonics/                   # Домен 1: Тектоника плит и литология
    │   ├── mod.rs
    │   ├── tectonics_config.rs      # Параметры плит, шума, орогенеза и эрозии
    │   ├── tectonics_data.rs        # GeologyLayer, Plate, Volcano, RockType
    │   ├── tectonics_solver.rs      # Физика границ плит, горячих точек, пород и диффузии
    │   ├── tectonics_palettes.rs    # Палитры высот, плит и коренных пород
    │   └── tectonics_ui.rs          # Правая панель настроек тектоники
    │
    ├── climate/                     # Домен 2: Атмосфера и океанография
    │   ├── mod.rs
    │   ├── climate_config.rs        # Параметры инсоляции, барических поясов, ветров и влаги
    │   ├── climate_data.rs          # ClimateLayer, SeasonalSnapshot, ClimateSeason
    │   ├── climate_palettes.rs      # Палитры климата и 3D-гизмо стрелок ветров и течений
    │   ├── climate_ui.rs            # Правая панель настроек климата и выбора сезона
    │   └── solver/                  # Подмодули физического солвера климата:
    │       ├── mod.rs               # Параллельный расчет 3 сезонов (rayon) и предрасчет весов
    │       ├── continentality.rs    # Flood Fill водоемов и двойной BFS в радианах
    │       ├── thermodynamics.rs    # Радиационный баланс, альбедо льда и высотное охлаждение
    │       ├── circulation.rs       # Давление, сила Кориолиса, 3D-ветры и океанические течения
    │       └── moisture.rs          # Испарение, адвекция влаги, орографические и конвективные осадки
    │
    └── hydrology/                   # Домен 3: Почвы, речной сток и биомы
        ├── mod.rs
        ├── hydrology_config.rs      # Параметры выветривания, порогов рек и биомов
        ├── hydrology_data.rs        # HydrologyLayer, SoilType, Biome
        ├── hydrology_palettes.rs    # Палитры почв, влажности, биомов и спутникового вида
        ├── hydrology_ui.rs          # Правая панель настроек почв и гидрологии
        └── solver/
            ├── mod.rs               # Оркестратор поверхностных процессов и обратной связи с климатом
            ├── soils.rs             # Модель почвообразования CLORPT и текстура песок/ил/глина
            ├── rivers.rs            # Граф стока, заполнение бессточных впадин и аккумуляция потока
            └── biomes.rs            # Классификация биомов Уиттекера с учетом почв и речных пойм
```
